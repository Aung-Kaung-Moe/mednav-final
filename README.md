# MEDNAV — integrated local demo

Synthetic astronaut check-ins, SQLite persistence, inventory-aware prototype investigation navigation, React mission console and a pinned local decision engine.

**Start here: [TEAM_SETUP_GUIDE.md](TEAM_SETUP_GUIDE.md).** It covers clean installation, automatic seeding, optional offline voice, startup and tests. Clean-checkout verification is recorded in [FRESH_CLONE_VERIFICATION.md](FRESH_CLONE_VERIFICATION.md).

The manual frontend → FastAPI → SQLite → real-engine flow is the stable demo path. Voice recognition is experimental and may misrecognize known phrases; review/correct every transcript and form before saving. Mobile Incident Report header overflow is a known UI defect. Core-test success does not imply voice accuracy, clinical validation or NASA endorsement.

Radiation/microgravity/anatomy telemetry remains illustrative, and incident reports are local previews. NASA OSD-575 research is isolated from fictional crew records and the decision engine. No cloud service is needed for the installed core demo.
